Three original brand graphics, 1080 × 1350 opaque PNG, with editable SVG sources. Prepared for @tranquilfastapp on 18 October 2026. Nothing published or scheduled.

Order: `01-meet-tranquil-fast`, `02-your-routine`, `03-your-choice`. Captions, profile bio, launch-day alternatives and channel/tool recommendations are in [the launch kit](../Launch-Promotion-Kit-2026-10-18.md).

These are product-introduction graphics, not screenshots of a new feature. The first includes a decorative timer/brand illustration without fictional statistics. None contains the owner's name, weight or fasting history. Reuse of the earlier App Store screenshots on social platforms needs approval for the exact personal information/destination.

The first image says Coming soon on iPhone. Keep it as a pre-launch introduction or update/re-render that line after manual release and a successful public download. Avoid pairing it with a contradictory available-now caption. Captions for all posts must reflect the actual launch phase.

Regenerate with Sharp installed:

```sh
node render.cjs
```

If needed, `SHARP_MODULE_PATH` can point to the installed Sharp module. The script reads the editable SVGs without changing app code. `preview.png` is a contact sheet for review, not a post to upload instead of the originals. All three PNG exports were dimension/alpha checked and visually inspected together.
